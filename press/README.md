# RETINUE press kit

Media for a store page, captured from the game as of the art and interface pass (commits `55f9a31`, `555a744`).
Screenshots are 1920×1080 PNG; clips loop forever at 12 fps, each at 960×540 and at 1280×720 (`-1280`), all under 3 MB.
An example store page built from them: https://claude.ai/artifact/73gYdda8sYLieKWcdFVFYK (private until shared).

Short description (275 characters, under Steam's 300):

> You are the Monarch, a necromancer who never strikes. Lead a retinue of goofy dead down a crypt, one turn-based
> battle at a time: every piece moves, then strikes. Recruit the slain, fuse them into colossi, raise the fallen
> mid-fight. Lose a single battle and the run is over.
